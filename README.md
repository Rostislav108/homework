# Домашнее задание 21.2 «Основы вёрстки»

Учебный проект: свёрстанные страницы магазина на Bootstrap и простое
веб-приложение на Python, которое на любой GET-запрос отдаёт страницу «Контакты».

## Что внутри

```
homework/
├── index.html        # Главная: три карточки товаров
├── catalog.html      # Каталог: две карточки-превью
├── category.html     # Категория 1: сетка из шести карточек
├── contacts.html     # Контакты: форма (имя, email, сообщение)
├── 404.html          # Страница ошибки 404 (доп. задание)
├── 500.html          # Страница ошибки 500 (доп. задание)
├── css/style.css     # Дополнительные стили поверх Bootstrap
├── app.py            # Веб-сервер: GET → «Контакты», POST → печать в консоль
└── .gitignore        # .idea, venv/, __pycache__/, .env/, *.sqlite*
```

## Задание 1: вёрстка

Все страницы собраны на Bootstrap 5 (подключён по CDN) и имеют одинаковую
структуру: **хедер** с навигацией (Главная, Каталог, Задачи, Контакты),
**основной блок** с контентом и **футер**.

- `index.html` — три карточки «Товар 1…3»: цена, описание, кнопка «Купить»;
- `catalog.html` — две карточки с превью и кнопками View / Edit;
- `category.html` — шесть карточек в сетке 3 × 2 (на телефоне — в столбик);
- `contacts.html` — форма обратной связи.

## Задание 2: веб-приложение

`app.py` — сервер на стандартной библиотеке (`http.server`), без внешних зависимостей.

- **GET** на любой адрес → `200` и страница «Контакты» с `Content-Type: text/html; charset=utf-8`;
- HTML читается из файла через `with open(...)` (контекстный менеджер);
- **POST** → данные формы разбираются и печатаются в консоль, пользователь получает ту же страницу «Контакты»;
- неподдерживаемые методы (PUT, DELETE, PATCH) → страница `404.html`;
- если файл страницы не читается → `500.html` и код `500`.

### Запуск

```bash
python app.py
```

Затем открыть http://localhost:8000 — откроется страница «Контакты».
Отправка формы печатает в консоль поля `name`, `email`, `message`.

Проверка из терминала:

```bash
curl -i http://localhost:8000/
curl -i -X POST -d "name=Иван&email=ivan@example.com&message=Привет" http://localhost:8000/
```

## Как проверялось

- `curl -i` на GET: статус `200`, заголовок `Content-Type: text/html; charset=utf-8`;
- `curl -i -X POST`: в консоли сервера появляются поля формы, ответ — та же страница;
- `curl -i -X PUT`: статус `404` и страница `404.html`;
- все страницы открываются локально, сетка Bootstrap адаптивная.
